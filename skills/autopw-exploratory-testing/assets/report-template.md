## 备注

1. 已验证问题均应有与结论匹配的现场证据；“运行时已验证”不等于必须由浏览器验证。
2. 涉及 UI、DOM、导航、Console、CORS、Cookie/Storage 或 JavaScript 执行的结论必须有浏览器/Playwright 证据。
3. 报告中的每个本地链接在交付前必须确认文件存在；不得引用旧输出目录中的遗留证据。
4. 报告必须区分 Playwright MCP、Playwright Test 和其他宿主浏览器；只记录实际执行过的工具。
5. `COMMIT_TO_WORKTREE` 报告只能覆盖冻结变更清单及其直接回归路径，不得暗示已完成全仓库或全站审查。
